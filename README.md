# LS25 Hof-Dashboard

Lokales Windows-Dashboard fuer Landwirtschafts-Simulator 25. Es zeigt Live-Daten aus der zugehoerigen `FS25_HofDashboard`-Mod und bietet Werkzeuge fuer Hofuebersicht, Felder, Fuhrpark, Tierhaltung, Produktion, Marktpreise, Vertraege und AutoDrive.

## Aktuelle Version

- Dashboard: `5.1.0`
- kompatible Mod: `FS25_HofDashboard` ab `5.1.0`
- Protokollversion: `1`

## Installation

1. Den aktuellen Release herunterladen: `HofDashboard-win-x64-v5.1.0.zip`
2. ZIP vollstaendig entpacken.
3. `HofDashboard.exe` starten.
4. Die passende Mod `FS25_HofDashboard.zip` im LS25-Modordner aktivieren.
